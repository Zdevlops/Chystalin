# Chystalin

Pemutar musik offline untuk Android.

## Fitur
- Impor lagu dari penyimpanan (disalin ke penyimpanan aplikasi, jadi tetap bisa diputar offline)
- Unduh lagu dari tautan langsung ke berkas audio (.mp3, .m4a, .ogg, .flac)
- Pustaka musik offline
- Playlist dengan urutan putar yang bisa diatur
- Rotasi putar: sekali putar, ulang semua, ulang satu, acak
- Pemutar layar penuh + mini player
- Layanan pemutaran di latar belakang (MediaSession)

## Build
APK dibangun otomatis lewat GitHub Actions. Hasil build ada di tab **Releases**
atau **Actions > Build Chystalin APK > artifact**.

## Catatan unduhan
Fitur unduh hanya menerima tautan langsung ke berkas audio. Tautan halaman
pemutar (YouTube, Spotify, dsb.) tidak didukung.
